# نبض · مختبر الدوائر

برنامج عربي لمحاكاة الدوائر الكهربائية والإلكترونية، مصمم لطلاب قسم الاتصالات في التعليم المهني العراقي بديلاً أسهل من Electronics Workbench.

## التشغيل

يحتاج [Node.js](https://nodejs.org) الإصدار 20 أو أحدث، و[Rust](https://rustup.rs) مع هدف WebAssembly وأداة wasm-bindgen:

```bash
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.129 --locked
```

```bash
npm install
npm run dev
```

ثم افتح http://localhost:5173 في المتصفح.

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | تشغيل البرنامج أثناء التطوير |
| `npm test` | كل الاختبارات: الواجهة على محرك Rust، ثم اختبارات المحرك نفسه |
| `npm run test:ts-engine` | نفس اختبارات الواجهة على المحرك القديم (TypeScript) للمقارنة |
| `npm run bench` | مقارنة سرعة المحرك القديم والجديد |
| `npm run golden` | إعادة تسجيل النتائج المرجعية من المحرك القديم |
| `npm run catalog` | تحديث `catalog/parts.json` بعد تعديل مكتبة القطع |
| `npm run build` | تطبيق ويب يعمل بدون إنترنت ويثبت على الهاتف، في مجلد `dist/` |
| `npm run build:desktop` | تطبيق ويندوز: ملف تثبيت في `target/release/bundle/nsis/` |
| `npm run build:android` | تطبيق أندرويد موقّع (APK) في `src-tauri/gen/android/app/build/outputs/apk/universal/release/` |
| `npm run build:single` | ملف واحد `dist-single/nabd.html` يفتح بالنقر المزدوج بدون إنترنت ولا تثبيت |

## التطبيقات (ويندوز وأندرويد)

البرنامج نفسه مغلّف بـ [Tauri](https://tauri.app) في تطبيق حقيقي يعمل بدون إنترنت:

- **ويندوز:** ملف تثبيت صغير (نحو 5 ميغابايت) لا يحتاج صلاحيات المدير. ملفات `.nabd` تُفتح بالنقر المزدوج عليها، حتى الواصلة عبر تيليكرام.
- **أندرويد:** ملف APK موقّع يعمل على أندرويد 7 فما فوق.

بناء أندرويد يحتاج JDK 17 وAndroid SDK وNDK. السكربت يجدها في أماكنها المعتادة على ويندوز.

**مفتاح التوقيع** في المجلد `school project/nabd-signing/`، خارج المستودع. احتفظ بنسخة منه على فلاشة: كل تحديث لاحق للتطبيق يجب أن يوقَّع بنفس المفتاح، وإلا يرفض الهاتف تثبيت التحديث فوق النسخة القديمة.

## الاستخدام في المدرسة بدون إنترنت

- **على حواسيب المختبر:** شغّل `npm run build:single` مرة واحدة، ثم انسخ الملف `dist-single/nabd.html` إلى أي حاسوب بفلاشة. يفتح بالنقر المزدوج في Chrome أو Edge.
- **على الهاتف:** انشر محتوى مجلد `dist/` على أي استضافة (مثل GitHub Pages)، وافتح الرابط مرة واحدة، ثم اختر «إضافة إلى الشاشة الرئيسية». بعدها يعمل بدون إنترنت.

## أهم الميزات

- **سماعة وجرس يصدران صوتاً حقيقياً:** السماعة تعزف التردد الذي تنتجه الدائرة فعلاً.
- **تحديات الصيانة:** دائرة فيها قطعة تالفة مخفية، والطالب يقيس ويجدها ويستبدلها.
- **إنجازاتي:** أوسمة يكسبها الطالب وهو يجرّب ويتعلم، محفوظة على جهازه.
- **جولة تعريفية** في أول تشغيل.

- **إدخال القيم:** الطالب يكتب الرقم فقط ويختار الوحدة من القائمة (كيلو، ميكا، ميلي، مايكرو…).
- **راسم الإشارة:** RUN/STOP، TIME/DIV و VOLTS/DIV، ربط DC/AC، قدح، عتلة زمن للرجوع والتقدم، مؤشرات Δt و 1/Δt، وقياس تلقائي للتردد والزمن الدوري و Vp-p و Vrms.
- **راسم بودي** مع تردد القطع، و**منحني الخواص** للثنائيات والترانزستورات.
- **طبيب الدائرة** يشرح الأخطاء بالعربي، والقطع تحترق عند تجاوز حدودها.

## بنية المشروع

محرك المحاكاة مكتوب بلغة Rust ويعمل في المتصفح عبر WebAssembly، أسرع من المحرك القديم بمرتين إلى أربع مرات. نتائجه تطابق المحرك القديم في 48 دائرة مرجعية بفرق لا يتجاوز 10⁻¹³ من المدى.

```
crates/core/       محرك المحاكاة (Rust، بلا واجهة)
├── src/doc.rs        شكل ملف الدائرة
├── src/catalog.rs    أطراف القطع وقيمها (من catalog/parts.json)
├── src/netlist.rs    تحويل الرسم إلى عقد كهربائية
├── src/stamp.rs      بناء المعادلات
├── src/linalg/       حل المعادلات (LU مع إعادة الاستخدام، والأعداد المركبة)
├── src/devices/      نموذج كل عائلة قطع في ملف خاص
├── src/engine.rs     الحل الزمني بطريقة نيوتن-رافسون
├── src/trace.rs      تشغيل دفعة خطوات مع تسجيل راسم الإشارة
├── src/doctor.rs     فحوص «طبيب الدائرة»
├── src/curves.rs     منحني الخواص
└── tests/golden.rs   مقارنة بنتائج المحرك القديم (tests/golden/*.json)
crates/wasm/       ربط المحرك بالمتصفح
catalog/parts.json  بيانات القطع المشتركة بين الواجهة والمحرك
src/
├── model/     الدائرة: أنواع البيانات، مكتبة القطع، عمليات التحرير
├── sim/wasm/  تحميل محرك Rust وواجهته (WasmEngine)
├── sim/       المحرك القديم بلغة TypeScript، مرجع للمقارنة فقط
│   ├── netlist.ts   تحويل الرسم إلى عقد كهربائية
│   ├── stamper.ts   بناء المعادلات G·v = i وحلها
│   ├── devices.ts   نماذج القطع (مقاومة، ثنائي، ترانزستور، بوابات…)
│   ├── engine.ts    الحل الزمني بطريقة نيوتن-رافسون
│   └── doctor.ts    فحوص «طبيب الدائرة» قبل التشغيل
├── ui/        الواجهة: اللوحة، الرموز، الألواح الجانبية، راسم الإشارة
├── lessons/   تجارب المنهج مع التحقق التلقائي
├── examples.ts  أمثلة جاهزة من كتاب التدريب العملي
└── i18n.ts    النصوص العربية والإنكليزية
tests/         اختبارات المحاكاة
src-tauri/     تطبيق ويندوز وأندرويد (Tauri)
docs/curriculum.md  خريطة تمارين الكتب وما يغطيه البرنامج
```

## إضافة قطعة جديدة

1. أضف تعريفها في `src/model/library.ts` (الاسم، الأطراف، الخصائص)، ثم `npm run catalog`.
2. ارسم رمزها في `src/ui/symbols.ts`.
3. اكتب نموذجها الكهربائي في ملف من `crates/core/src/devices/` وأضفه إلى `create` في `devices/mod.rs`.
4. أضف اختباراً في `tests/` أو في `crates/core`.
