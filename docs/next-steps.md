# نبض: ما بقي من مقترحات (حتى 2026-10-01)

الحالة الآن:
- كل تجارب المنهج في `docs/curriculum.md` تعمل.
- محرك المحاكاة صار بلغة Rust (WebAssembly)، ونتائجه تطابق المحرك القديم. 112 اختبار واجهة و9 اختبارات محرك تنجح.
- الأولوية الآن (حسب طلب المدرسة): المحاكاة نفسها وجعلها ممتعة للطالب على حاسوب البيت والهاتف، وتطبيق ويندوز وأندرويد بـ Tauri. الواجبات وتصحيح الأستاذ والامتحانات لاحقاً.
- النسخة الواحدة بدون إنترنت هي `school project/نبض.html`.
- آخر إصلاح: قائمة القطع لم تعد تُقص، والأقسام تنزل لسطر ثانٍ.

## 1. التوزيع (أهم شيء، ومؤجل لبناء واحد)
- [ ] **ملف تثبيت ويندوز** (Tauri أو Electron)، مع أيقونة واسم «نبض» واختصار على سطح المكتب. يجب أن يعمل بدون إنترنت.
- [ ] **تطبيق أندرويد APK** (Capacitor): واجهة اللمس جاهزة، يبقى التغليف والتوقيع.
- [ ] إصدار رقم النسخة وصفحة «حول البرنامج».

## 1.5 المحرك
- [ ] حلّال مصفوفات متفرقة (sparse LU) للدوائر الكبيرة (أكثر من 40 عقدة)، حيث المحرك الحالي يبطؤ.
- [ ] تشغيل المحرك في Web Worker حتى لا تتأثر الواجهة أبداً.
- [ ] تصغير ملف wasm (wasm-opt).

## 2. مراجعة شاملة للكود
- [ ] إعادة المراجعة الآلية الكاملة التي توقفت بسبب حد الاستخدام: المحاكاة، والواجهة، والأداء مع الدوائر الكبيرة.
- [ ] تجربة البرنامج على أجهزة المدرسة الضعيفة (حاسبات قديمة، متصفح قديم).

## 3. تحسينات للطالب والمدرس (اختيارية)
- [ ] **حفظ وفتح ملفات الدوائر** باسم واضح (.nabd) مع معاينة صغيرة.
- [ ] **طباعة أو تصدير الدائرة** صورةً أو PDF لتقرير التجربة، مع جدول القراءات.
- [ ] **وضع الامتحان:** المدرس يخفي القراءات أو يقفل بعض القطع، والطالب يجيب.
- [ ] **ورقة عمل:** جدول قراءات يملؤه الطالب أثناء التجربة، والبرنامج يقارنه بالقيم الصحيحة.
- [ ] دروس تفاعلية أكثر: 12 درساً حالياً، والهدف درس لكل تجربة في الكتب الثلاثة.
- [ ] أعطال مقصودة يكتشفها الطالب، مثل مقاومة مفتوحة أو متسعة تالفة (تمرين صيانة).
- [ ] أصوات خفيفة اختيارية (صوت السماعة أو الجرس عند تشغيله في الدائرة).

## 4. تحسينات في الواجهة (صغيرة)
- [ ] تغيير عرض قائمة القطع ولوحة الخصائص بالسحب.
- [ ] قطع «المفضلة» أو «المستخدمة مؤخراً» أعلى القائمة.
- [ ] جولة تعريفية أول مرة (خطوة بخطوة على الأزرار).
